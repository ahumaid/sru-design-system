# Project instructions for AI agents

- This is an internally hosted project maintained only by Design team members.
  People outside the team do not have access to the repository or source files;
  they are consumers of the published CSS and JavaScript components.
- AI agents working on this project receive direction from the Design team, not
  from component consumers. Follow the designers' instructions when making
  project changes.
- Write user-facing text, documentation, and instructions for those consumers.
  Assume they use the published components in their own projects, and do not
  direct them to internal source files, repository workflows, or team-only
  processes.
- Ensure all human-readable text shipped in project outputs is available in
  Arabic. This applies to webpage content, consumer documentation, and
  instructions; provide English alongside Arabic when the interface supports
  both languages. Keep literal technical content unchanged where translation
  would break or alter it, such as HTML/code snippets, URLs, identifiers, API
  names, and command names. This language requirement applies to project
  artifacts, not agent conversation with the Design team.
- `src/styles/sru-theme.scss` is the only stylesheet source.
- Use Bootstrap 5.3.8 components, utilities, and existing theme tokens. Do not
  write custom CSS or Sass rules, add stylesheets, or use inline styles for
  visual design. If the available system does not support a requested design,
  ask the Design team for direction.
- Files under `public/design-system/` are generated by `npm run build:assets`;
  edit the Sass source instead of hand-editing generated CSS or JavaScript.
- The published CSS bundles include Bootstrap 5.3.8. Consumers should not load
  a second Bootstrap stylesheet.
- `npm run build` regenerates both direction-specific CSS bundles, copies the
  matching Bootstrap JavaScript bundle, and builds the Cloudflare Pages site.
